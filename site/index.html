Objekte zum Anfassen.
Python zum Verstehen.

BluePy ist die Lern-IDE für Python in deinem Informatikunterricht: Klassendiagramm, Objektleiste, Methoden anklicken, Inspektor, Debugger, Unit-Tests. Objektorientierung, die man sieht.

Download Code auf GitHub

Braucht nur ein installiertes Python ab 3.11. Kein Account, keine Cloud, nichts wird gesendet.

macOS-Builds sind mit Apple Developer ID signiert und notarisiert. Windows: Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Funktionen

Objekte zum Anfassen, bevor eine Zeile main-Code geschrieben ist.

Erst Objekte, dann Code: Schüler:innen sehen Klassen und Objekte, bevor sie die erste Zeile schreiben. Ohne Terminal-Gefummel, ohne if __name__ == "__main__" in der ersten Stunde.

Klassendiagramm

Aus deinem Code, live beim Speichern. Vererbung, Assoziationen mit 1 : n, Komposition, Benutzt-Pfeile. Klassen verschieben, Layout bleibt im Projekt.

Objektleiste

Rechtsklick auf eine Klasse → new Konto(…). Rechtsklick aufs Objekt → Methode aufrufen, auch geerbte. Rückgabewert im Dialog und im Terminal.

Inspektor

Jedes Objekt aufklappen: Attribute, Typen, Werte. In verschachtelte Objekte und Listen reinklicken, Werte auf die Objektleiste holen.

Code Pad

Ausdrücke und Anweisungen sofort ausprobieren. Was du dort erzeugst, liegt auf der Objektleiste und lässt sich inspizieren.

Debugger

Breakpoint per Klick in die Zeile, Step / Step Into / Step Out, Variablen live. Halt stoppt jede Endlosschleife.

Unit-Tests

Testklasse anlegen, Tests per Klick aufnehmen: jede Interaktion wird Code, Assertions kommen aus dem Ergebnisdialog. Ergebnisfenster mit grünem oder rotem Balken. Basis: unittest.

Scope-Highlighting

Klasse grün, Methode gelb, Schleife blau, Verzweigung lila. Verschachtelte Blöcke als Kästen hinter dem Code, so sieht man Einrückung, bevor man sie versteht.

Sechs Beispielprojekte

Python-Grundlagen mit Übungsaufgaben, Bank, Tierpark, Quest-Spiel, Datenstrukturen und Geheimschrift: vom ersten Tag bis zum Abitur, jedes mit Tests.

Vervollständigung

Pyright im Hintergrund: Methoden und Attribute beim Tippen, Docstrings beim Darüberfahren, Tippfehler in Namen sofort markiert. Dein installiertes Python (ab 3.11) genügt.

Im Unterricht

Eine Stunde mit BluePy.

1

Projekt öffnen

Dein Projektordner mit .py-Dateien oder das Beispiel „bank“. Compile, und das Klassendiagramm steht.

2

Objekte erzeugen, Methoden aufrufen

Schüler:innen klicken sich durch Konstruktor und Methoden, sehen Rückgabewerte und Fehlermeldungen, inspizieren den Zustand. Erst dann schreiben sie Code.

3

Code ändern, sofort prüfen

Editor mit Syntaxprüfung beim Tippen, Compile mit ⌘K, Objekte neu erzeugen. Breakpoint setzen, wenn etwas unklar ist.

4

Tests statt Behauptungen

Testmethode aufnehmen, Assertion anklicken, Tests ausführen. Grün oder rot, für die ganze Klasse auf einen Blick.

Aufgaben verteilen und einsammeln

Ohne Logins, ohne Git, ohne Mail. Der BluePy-Hub ist ein kleiner Server, auf dem Aufgaben und Abgaben liegen.

  1. Du veröffentlichst ein Projekt als Aufgabe: Beschreibung, Zeitfenster, Aufgabencode.
  2. Schüler:innen holen die Aufgabe mit dem Code und geben per Klick ab. Persönlicher Code statt Account.
  3. Du sammelst alle Abgaben mit einem Klick ein und korrigierst direkt in BluePy: durchklicken, Tests laufen lassen, Notizen und Punkte.

Mitmachen: Der Hub läuft bei mir. Schreib mir eine Mail, du bekommst deinen Lehrer-Schlüssel und legst los. Du willst die Daten bei dir? Der Hub ist Open Source und läuft als ein Docker-Container auf jedem kleinen Server, Anleitung liegt im Repo.
